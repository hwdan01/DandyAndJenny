THE LOVE LETTER — 200 DAYS
============================

How to open:
1. Unzip this folder if it isn't already.
2. Double-click "index.html" — it will open in your default browser
   (Safari, Chrome, etc).
3. Tap a letter in the jar to unfold it. Use the arrows (or the dots
   at the bottom) to move between pages, and the "back to the jar"
   button to return.

No internet connection is needed — everything (fonts, styling,
animations) is built into this one file.

Works on Mac, Windows, and mobile browsers.
